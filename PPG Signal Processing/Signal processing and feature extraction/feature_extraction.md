
### PPG feature list for glucose-change association analysis

### 1\. Time-domain waveform features

* Pulse amplitude

* Peak-to-peak amplitude

* Pulse width

* Pulse width at 50% amplitude (FWHM)

* Pulse width at 25% amplitude

* Pulse width at 75% amplitude

* Rise time

* Fall time

* Time to systolic peak

* Pulse duration

* Pulse area

* Systolic area

* Diastolic area

* Pulse amplitude variability

* Pulse width variability

* Beat-to-beat waveform variability

### 2\. Pulse timing features

* Pulse-to-pulse interval (PPI)

* Inter-beat interval (IBI)

* Heart rate (HR)

* HR variability (HRV)

* Mean IBI

* SD of IBI

* RMSSD

* SDNN

* pNN50

* Frequency of pulse occurrences

### 3\. Morphological features

* Systolic peak amplitude

* Diastolic peak amplitude

* Dicrotic notch amplitude

* Dicrotic notch position

* Dicrotic notch depth

* Dicrotic notch timing

* Systolic-to-diastolic amplitude ratio

* Peak-to-notch ratio

* Notch-to-peak interval

* Reflection wave amplitude

* Reflection index

* Augmentation index (PPG-derived)

* Pulse symmetry

* Pulse skewness

* Pulse kurtosis

### 4\. Derivative-based features

* First derivative (VPG) features

* Second derivative (APG) features

* Maximum first derivative

* Minimum first derivative

* Maximum second derivative

* Minimum second derivative

* Derivative peak amplitudes

* Derivative peak timings

* Ratios of second-derivative wave components (a, b, c, d, e)

* b/a ratio

* c/a ratio

* d/a ratio

* e/a ratio

* Aging index (APG-derived)

### 5\. Statistical features

* Mean

* Median

* Standard deviation

* Variance

* Coefficient of variation

* RMS (root mean square)

* Skewness

* Kurtosis

* IQR

* MAD (median absolute deviation)

* Minimum

* Maximum

* Range

### 6\. Frequency-domain features

* Dominant frequency

* Spectral power

* Total spectral energy

* Low-frequency power

* High-frequency power

* LF/HF ratio

* Frequency-domain HRV features

* Spectral entropy

* Spectral centroid

* Spectral bandwidth

### 7\. Nonlinear features

* Sample entropy

* Approximate entropy

* Permutation entropy

* Shannon entropy

* Detrended fluctuation analysis (DFA)

* Poincaré plot features (SD1, SD2)

* Fractal dimension

* Lyapunov exponent (where appropriate)

### 8\. Signal quality and perfusion-related features

* Signal quality index (SQI)

* Perfusion index (PI)

* Pulse strength

* Pulse detectability

* Signal-to-noise ratio (SNR)

* Baseline variation

* DC component

* AC component

* AC/DC ratio

* PPG baseline drift

### 9\. Multi-window aggregated features

* Mean feature value per 1-minute window

* Mean feature value per 5-minute window

* Median feature value per 5-minute window

* SD per 5-minute window

* Trend/slope per window

* Percentage change from baseline

* Relative change

* Feature variability within window
