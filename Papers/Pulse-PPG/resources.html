Glossary

TermMeaning
PPGPhotoplethysmography; optical measurement of blood-volume changes.
Domain shiftDifference between training and deployment data distributions.
Foundation modelBroadly pretrained model whose representations can be reused across tasks.
MotifRecurring local pattern in a time series.
Cross-attentionQueries from one sequence attend to keys and values from another.
RelConRelative contrastive learning; contrastive relationships informed by relative distances.
Linear probeDownstream linear head trained while the pretrained encoder is frozen.
Fine-tuningUpdating pretrained parameters using downstream data.
Subject leakageInformation from the same person appearing across train and evaluation splits.
CalibrationAgreement between predicted confidence and empirical correctness/uncertainty.

Reading guide

  1. Read abstract and introduction for motivation and claims.
  2. Read the method while tracing motif-distance and RelCon equations.
  3. Read data and implementation details before interpreting results.
  4. Read each result table with its task definition and split protocol.
  5. Read discussion and limitations to identify open questions.
  6. Inspect code to distinguish paper descriptions from implementation choices.

Research integrity checklist

  • Do not treat windows as independent participants.
  • Do not infer clinical validity from benchmark performance alone.
  • Do not assume raw pretraining data are available because code is open.
  • Do not claim exact reproduction when preprocessing or splits differ.
  • Check novelty against monotonic alignment, dynamic time warping, optimal transport, and contrastive time-series learning.
  • Report negative results, compute budgets, and data limitations.
