Lesson 3 — Pulse-PPG Methodology

Learned motif distance followed by relative contrastive pretraining

← Previous lessonContentsNext →

1. Two-stage training

  1. Learn a motif-based distance: train a network to compare local PPG patterns using reconstruction-style cross-attention.
  2. Train the foundation encoder: use the learned distance to define relative relationships in a contrastive objective.

2. Motifs and local similarity

A motif is a recurring local waveform pattern. In PPG, local morphology may encode pulse shape, systolic upstroke, peak structure, and other characteristics. The model compares local regions even when they do not occur at exactly the same temporal position.

3. Cross-attention reconstruction distance

For anchor signal Xa and comparison signal Xc, the paper describes a distance based on reconstructing anchor features from comparison features:

d(Xa, Xc) = Σxₐ ∈ₛ Xₐ ‖ Σx꜀ ∈ₛ X꜀ α(xₐ,x꜀) fᵥ(x꜀) − xₐ ‖²

The attention weight is:

α(xₐ,x꜀) = softmaxx꜀(sim(fq(xₐ), fk(x꜀)))

Here fq, fk, and fv are learned feature mappings. An anchor query attends over comparison keys; comparison values are combined to reconstruct the anchor feature.

4. Masked local reconstruction intuition

The described setup uses a local region of approximately two seconds (100 samples at 50 Hz) as the target region. The network learns whether a pattern in one signal can be reconstructed from patterns in another signal. This is local feature matching, not simply global waveform alignment.

5. Why the distance is directional

In general d(Xa,Xc) need not equal d(Xc,Xa). One signal may contain motifs that reconstruct the other well, while the reverse may not. Do not automatically treat it as a symmetric metric satisfying all metric axioms.

6. Relative contrastive learning

𝒩ᵢ = { X : d(Xₐ,X) > d(Xₐ,Xᵢ) }

For anchor Xa and positive candidate Xi, examples farther from the anchor than the positive candidate can be used as negatives in the corresponding contrastive comparison. This is a relative ordering rather than a fixed declaration that every other segment is negative.

The foundation encoder maps a segment to an embedding. Its contrastive loss encourages the embedding similarity structure to agree with distance-based relationships. The motif-distance network supplies supervisory structure; it is not simply the same encoder being optimized by the contrastive loss.

7. Critical questions

  • Does local motif matching preserve global temporal order?
  • Can the model exploit subject identity or device artifacts instead of physiology?
  • How should asymmetric distances be handled when defining candidate relationships?
  • Do attention weights reveal physiological correspondence or merely useful model behavior?
Implementation caution

The equations are a conceptual guide, not a complete executable specification. They may omit projections, normalization, or implementation-specific tensor operations. Verify the repository before claiming exact reproduction.
