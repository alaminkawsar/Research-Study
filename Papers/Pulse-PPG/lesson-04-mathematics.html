Lesson 4 — Mathematical and Tensor-Shape Deep Dive

Cross-attention, computational cost, gradients, and a possible temporal-order extension

1. Input and tensor dimensions

A four-minute segment sampled at 50 Hz contains:

4 × 60 × 50 = 12,000 samples

The described motif setup uses feature dimension 64 and subsamples at stride 10, giving approximately 1,200 temporal positions. The foundation encoder produces a 512-dimensional embedding.

StageIllustrative tensor shape
Input batch[B, 1, 12000]
Q, K, V features[B, 64, 12000]
Subsampled features[B, 64, 1200]
Attention matrix[B, 1200, 1200]
Foundation embedding[B, 512]

These shapes summarize the conceptual pipeline. Inspect implementation for channel order, projection dimensions, and subsampling location.

2. Cross-attention

For one batch, write Q and K as feature-by-time matrices. A similarity matrix is:

S = QᵀK

After a row-wise softmax across comparison positions, obtain attention weights A. The reconstructed feature sequence is a weighted combination of values:

A = softmax(S),    X̂ₐ = AVᶜ

The exact transpose convention depends on whether time is represented along rows or columns. Each anchor position forms a distribution over comparison positions.

3. Gradient intuition

e = ‖x̂ − x‖²,    x̂ = Σⱼ αⱼvⱼ

For softmax attention over scores sj:

∂e/∂sₗ = 2αₗ (x̂ − x)ᵀ(vₗ − x̂)

Attention scores are updated according to whether a value vector helps or hurts reconstruction relative to the current weighted average.

4. Computational implications

Full attention over 12,000 positions requires a 12,000 × 12,000 score matrix per example. Subsampling to 1,200 positions reduces pairwise entries by about 100×:

(12,000²) / (1,200²) = 100

Actual runtime also depends on convolutional feature extraction, batch size, memory layout, and hardware.

5. Relative contrastive stage

The motif-distance model supplies relationships between examples. The foundation encoder learns an embedding space trained to respect those relationships. The distance model is a source of supervisory structure, not the final representation network itself.

6. Candidate temporal-order penalty

Let Pij represent alignment weight between position i in one signal and position j in another. A possible crossing penalty is:

Lorder = Σi<k Σj>l PijPkl
L = LRelCon + λLorder

This is a proposal, not part of the original Pulse-PPG objective. It needs careful normalization and complexity analysis. A strict order constraint may penalize legitimate physiological timing variation, so soft alignment and a tunable penalty are worth investigating.

Questions to resolve

  • Is P normalized attention, a soft alignment, or a transport plan?
  • Should the penalty apply to all positions or only selected motifs?
  • Should the distance be regularized in both directions?
  • How can the implementation avoid a costly four-index summation?
